# Guia de carregamento programado · Goldenergy

Percurso responsivo em React, Vite e Tailwind: veículo, horário, passos na app e conclusão. Suporta português, espanhol, inglês, francês e alemão, com HTML estático por idioma gerado durante o build. Sitemap, `robots.txt`, títulos locais, canónicos, `hreflang` e metadados sociais são gerados a partir do conteúdo traduzido. Para rever as decisões editoriais/SEO, configurar verificações ou publicar, consulte `INSTRUCOES.md`.

Com Node.js 22 e as dependências do projeto instaladas, execute `npm run dev`. `npm test` verifica o percurso, as seleções e as ligações partilháveis; `npm run build` produz a pasta `dist`.

Para publicação e testes em desktop e telemóvel, consulte `INSTRUCOES.md`.
